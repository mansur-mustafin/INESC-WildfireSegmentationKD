# Fire Detection

## How to use

* Create virtual environment:
    * `python -m venv venv`
    * `pip install -r requirements.txt`

* Run the code:
    * Download the Sen2Fire dataset using this [link](https://zenodo.org/records/10881058) and place the downloaded `Sen2Fire/` folder under the `datasets/` directory.
    * From the repository root, use `python3 -m src.wildfire_kd.train` or `python3 -m src.wildfire_kd.kd-train`.
